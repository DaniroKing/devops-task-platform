# DevOps Task Platform

Учебный DevOps-проект, демонстрирующий полный жизненный цикл веб-приложения: разработку, тестирование, контейнеризацию, автоматическую сборку, развёртывание, мониторинг и обеспечение безопасности.

## Цель проекта

Создать production-подобную инфраструктуру для Python FastAPI-приложения с PostgreSQL.
